# ⚡ DevFlow - Landing Page

Uma landing page moderna e responsiva criada para apresentar o **DevFlow**, uma ferramenta fictícia de organização de tarefas, projetos e rotinas de estudo voltada para desenvolvedores.

Este projeto foi desenvolvido como meu segundo passo prático nos estudos de desenvolvimento Web, com o objetivo de consolidar conceitos essenciais de estruturação e estilização.

## 🎯 Conceitos e Práticas Aplicadas
- **HTML5 Semântico:** Estruturação utilizando tags semânticas (`<header>`, `<nav>`, `<section>`, `<main>`, `<footer>`).
- **CSS3 Moderno:**
  - Uso de **Flexbox** para alinhamento e distribuição da barra de navegação e seções principais.
  - Implementação de **CSS Grid** (`auto-fit`, `minmax`) para a grade de cards responsiva.
  - Efeitos de transição, estados de interatividade (`:hover`) e elevação visual de elementos.
  - Estilização com gradientes radiais e paleta de cores no estilo *dark mode*.

## 🚀 Como Executar
1. Clone este repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web.
